### 🕵️ OSINT & Reconnaissance Tools

A curated list of tools for OSINT and reconnaissance activities.

| Tool | Category | Description | Link |
| :--- | :--- | :--- | :--- |
| **Recon-ng** | Recon Framework | A powerful environment for web-based reconnaissance. | [GitHub](https://github.com/lanmaster53/recon-ng) |
| **HTTPScreenshot** | Web Screenshotting | Grabs screenshots of websites over HTTP and HTTPS. | [GitHub](https://github.com/breenmachine/httpscreenshot) |
| **EyeWitness** | Web Screenshotting | Takes screenshots, gathers server info, and identifies default credentials. | [GitHub](https://github.com/RedSiege/EyeWitness) |
| **AWS IP Ranges** | Cloud IP Ranges | The official JSON file of Amazon's public IP address ranges. | [JSON File](https://ip-ranges.amazonaws.com/ip-ranges.json) |
| **Google Cloud IPs** | Cloud IP Ranges | The official list of IP ranges Google makes available on the internet. | [JSON File](https://www.gstatic.com/ipranges/goog.json) |
| **Azure IP Ranges** | Cloud IP Ranges | The official download page for Azure datacenter IP ranges. | [Download](https://www.microsoft.com/en-us/download/details.aspx?id=56519) |
| **Shodan** | Search Engine | A search engine for finding specific types of computers on the internet. | [Website](https://www.shodan.io/) |
| **Domain Dossier** | Domain Investigation | Investigates domains and IP addresses by aggregating public records. | [Website](https://centralops.net/co/DomainDossier.aspx) |
| **Houndog** | Code Scanning | A tool to help you find secrets and credentials in code commits. | [GitHub](https://github.com/houndog/houndog) |
