[Instructions for Maltego Integration]
---------------------------------------
This document explains how to import the results of the OSINT scan into Maltego for visualization and further analysis.

Prerequisites:
- Maltego Desktop Client installed.
- The OSINT scan has been run, and you have an output directory (e.g., /opt/output/osint_username_timestamp).

Steps:
1.  **Open Maltego and Start a New Graph.**
    - Launch the Maltego client.
    - Create a new, blank graph.

2.  **Create the Primary Alias Entity.**
    - From the Entity Palette (usually on the left), find the "Alias" entity.
    - Drag it onto the graph.
    - Double-click the entity and change its value to the username you investigated.

3.  **Import Data from Sherlock and Maigret.**
    - The automated scans produce several files. The most useful for direct import are often the CSV files generated by Maigret.
    - Locate the `.csv` file in your output directory (e.g., `maigret_results.csv`).
    - You can import this data into Maltego. (Note: Specific import steps can vary based on your Maltego version).
    - For data that is not in a CSV format (like `sherlock_results.txt`), you can manually copy and paste the URLs and other information to create new entities in your graph.

4.  **Create and Link New Entities.**
    - Based on the data from the output files, create new entities. For example:
      - Drag a "Website" entity onto the graph for each URL found by Sherlock.
      - Drag a "Social Media Profile" entity for each confirmed profile.
      - If you find email addresses or phone numbers, use the corresponding entities.
    - Link these new entities back to your main "Alias" entity.

5.  **Run Transforms.**
    - Once you have populated your graph with entities, you can run Maltego transforms to discover more information.
    - Right-click on an entity (like a website or email address) and select from the available transforms to find related domains, IP addresses, social media profiles, etc.

6.  **Add Notes and Attachments.**
    - You can add notes to any entity to store additional context.
    - You can also attach files, such as the EXIF report or other text files from the scan results, to relevant entities for a complete picture.

By following these steps, you can build a comprehensive visual map of your target's online presence, which can help you uncover connections and insights that are not immediately obvious from the raw data.
