# Automated OSINT Investigation Toolkit

This project provides a powerful, Dockerized environment for conducting OSINT (Open-Source Intelligence) investigations. It uses a flexible configuration file to automate a prioritized workflow, allowing you to efficiently gather and analyze information about your subject.

## Features

- **Dockerized Environment**: The entire toolchain is containerized, ensuring a consistent and easy-to-set-up environment.
- **Flexible Configuration**: Use the `subject.yml` file to define your target's information (usernames, emails, etc.) and select which tools to run for each investigation.
- **Prioritized Workflow**: The main script runs tools in a logical order, from broad enumeration to deep analysis.
- **Anonymized Requests**: Sherlock and Maigret scans are routed through the Tor network to enhance privacy.
- **Comprehensive Tooling**:
  - **Sherlock**: For broad username enumeration across hundreds of social networks.
  - **Maigret**: For deeper profile analysis and correlation.
  - **SpiderFoot**: For extensive, automated footprinting and intelligence gathering (via a web UI).
  - **exiftool**: For metadata analysis of media files.
- **Persistent Results**: All scan results are saved to a local, timestamped `output` directory, organized by username.
- **Maltego Integration**: Includes clear instructions for importing and visualizing your results in Maltego.

## Prerequisites

Before you begin, ensure you have the following installed on your system:
- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

## How to Use

The investigation workflow is managed through a central configuration file.

### Step 1: Build the Docker Image

First, build the Docker image which contains all the necessary tools. This may take some time on the first run.
```bash
docker-compose build
```

### Step 2: Configure Your Investigation

Create your investigation file by copying the provided template.
```bash
cp subject.yml.example subject.yml
```
Now, open `subject.yml` in a text editor and:
1.  Fill in the `subject_data` section with all the information you have on your target (e.g., usernames, emails).
2.  In the `tool_config` section, set tools to `true` or `false` to enable or disable them for this specific investigation.

### Step 3: Run the Automated Scan

Once your `subject.yml` is configured, start the services and execute the main orchestration script.

First, launch the services in the background. This also starts the SpiderFoot web UI.
```bash
docker-compose up -d
```

Next, run the script. It will automatically read your `subject.yml` file.
```bash
docker-compose exec osint-stack ./run_osint.sh
```
The script will create a new timestamped output directory inside the `./output` folder and run the selected tools for each username you provided.

### Step 4: Access Your Results

All files generated by the script (Sherlock reports, Maigret PDFs, logs, etc.) will be available in a new directory inside the `output` folder on your host machine, neatly organized by username.

### Step 5: Deeper Investigation with SpiderFoot

For more in-depth, automated reconnaissance, use the SpiderFoot web UI.
- **Access the UI**: Open your web browser and navigate to `http://localhost:5001`.
- **Start a Scan**: From the SpiderFoot UI, you can start new scans on various targets (usernames, domains, emails, etc.).
